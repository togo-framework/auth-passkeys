# auth-passkeys — docs

WebAuthn / passkey (FIDO2) passwordless login for the togo auth family.

- **Install:** `togo install togo-framework/auth-passkeys`
- **Marketplace:** https://to-go.dev/plugins/auth-passkeys
- **Source:** https://github.com/togo-framework/auth-passkeys

See [usage.md](usage.md) for the ceremony endpoints, config, and the browser flow.
